When · the Jev score

Knowing when to install is the job.

score = round(20 × (0.35T + 0.25A + 0.20D + 0.20E))
35%T · Time-to-value
25%A · Automation fit
20%D · Data readiness
20%E · Exit-safety
75+ · INSTALL NOW55–74 · QUEUE NEXTUNDER 55 · PARKExit-safety of 2 or less flags “Rework first.”

Each dimension is scored 1 to 5.
