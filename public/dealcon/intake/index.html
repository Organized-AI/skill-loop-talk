Scoring rubric

DimensionWeight5 looks like1 looks like
Time-to-value (T)35%First win from data and tools already in placeNeeds a new system, migration, and behavior change first
Automation fit (A)25%High volume, repetitive, rules-basedRare, judgment-heavy, relationship-driven
Data readiness (D)20%Structured data in an accessible system (CRM, database, API)Lives in someone's head, paper, or scattered inboxes
Exit-safety (E)20%Layer on mainstream tools, documented, transferableCustom platform, or one person the process can't run without
Score = 20 × (0.35·T + 0.25·A + 0.20·D + 0.20·E) → 20 to 100

75 and above: install now. 55 to 74: queue next. Below 55: park. Any process with exit-safety of 1 or 2 is flagged for rework before install, whatever its total.

In this workshop version you score each dimension yourself. The full harness adds calibrated probabilities from Jev decision models.
