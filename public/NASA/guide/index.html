The build lab

Four parts work together on one computer. The agent does the typing; the team makes every decision.

Build a change

Every change takes the same eight steps. Step five matters most: the agent asks, the team votes.

One change, step by step the rocket launch

  1. Pick a change. Look at the page, pitch ideas, vote for one. Team
  2. Write the prompt. Say exactly what to change, and to change nothing else. Team
  3. Send it. Paste it into T3 Code and hit send. The agent reads our files first. Mentor
  4. The agent makes a plan. It says what it will do, then waits for our OK. Agent
  5. The team votes. Read the request out loud. Hands up? Approve. Not what we asked for? Deny, and say why. Team
  6. Get the parts. npm downloads GSAP and adds it to package.json, the app’s parts list. Agent
  7. The agent writes code. It changes one file and tells us what it did. We can read every line. Agent
  8. Launch! Vite reloads the page by itself. Press Launch! together. It works? Make a save point: a git commit. Everyone

Press Launch!

One click makes a round trip in less than a second. Follow it like a meal in a restaurant: click, order, cook, serve.

One click, there and back Space Fact Machine

  • 1 · Clickdoor 5173You press Launch! on the page, the frontend. React sends an order: fetch("/api/fact"). Like the dining room.
  • 2 · OrderGET /api/fact“Get me a fact.” Vite passes anything that starts with /api to door 8000. The API is the menu.
  • 3 · Cookdoor 8000The backend (Python, FastAPI) picks one of six checked facts at random, with its source. Like the kitchen.
  • 4 · ServeJSONThe answer comes back as JSON, a filled-in form with labels. The page shows the fact and a Source: NASA chip.

The menu has two items. GET /api/health asks “are you awake?” and gets {"ok": true}. GET /api/fact gets one fact and its source. Anything else gets an error, not a fact.Server asleep? The page doesn’t crash. It says: “The fact server is asleep. Ask your mentor to wake it up.”

Words to know

  • Promptyour orderPlain-language instructions for the agent.
  • Frontendthe dining roomThe part of an app you see and click. Ours runs at door 5173.
  • Backendthe kitchenA program that waits for requests and sends back answers. Ours runs at door 8000.
  • APIthe menuThe list of requests a server knows how to answer.
  • localhostthis computerThe address your own computer uses for itself.
  • Porta numbered doorA way in to one program on the computer, like 5173 or 8000.
  • JSONa filled-in formText data with labels that people and programs can both read.
  • Commita save pointA snapshot of the code made with git, so you can always go back.

Three rules

  • The team decides.We voteThe agent asks; someone reads the request out loud; the team votes before anyone presses Approve.
  • One change at a time.Small stepsSmall changes are easy to check and easy to undo. Look at the page together before the next one.
  • Every fact needs a source.Show the sourceIn the app, in the pitch and in the NASA submission. We hand the agent its facts; it never makes them up.
