Eight words, each with what it’s like. A prompt is plain-language instructions for the agent. The frontend is the part you see and click; the backend waits for requests and answers them; the API is the list of requests a server knows how to answer. localhost is this computer, a port is a numbered door into it, JSON is text data people and programs can both read, and a commit is a saved snapshot made with git. Ask the team to explain each one back.
