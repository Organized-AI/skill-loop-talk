You’ve got the basics: the team decides, the agent asks, and we press Launch! Here are three next-level tools to research on your own, for after the basics click. One: DSH, the DeepSeek Harness. It’s an open-source app for running AI agents, built so every part is a plugin you can swap, like LEGO. One command starts its web page on your own computer, but it still needs an AI model behind it, and that needs an account. Research: which model, and what does it cost? Two: the DSH superagent, a research prototype from DeepSeek, not an official product. It watches one GitHub repo. When someone on its allowed list asks for work on an issue, it works in its own space and answers with a pull request. You set it up by asking your coding agent to read its SETUP.md with you. Research: does it ask before it acts? Our rule is that the team decides, so find out what it does on its own and who it listens to. Three: Cloudflare Workers. Right now Space Fact Machine only lives on our computer. A Worker runs code on Cloudflare’s network, so anyone with the link can open it; the web version of this deck runs on one. Research: how could our page go live, and what does the free plan cover? Start with each tool’s own docs: the READMEs on GitHub, and developers.cloudflare.com/workers.
