03 / 10

Four parts. The build environment is everything the computer needs to build and run an app, like a kitchen set up before you cook. T3 Code is mission control: where we tell the agent what to build. Claude Code is the agent; in Supervised mode it asks before it acts. The toolbox is Python for the backend, Node and npm for web tools, and git, whose commits are save points. The Claude login is the mentor’s, because Claude accounts are for adults; you can use your own GitHub accounts.
